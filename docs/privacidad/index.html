Esta Política de Privacidad explica cómo {{DEVELOPER_NAME}} (“nosotros”) recopila, usa y protege la información cuando utilizas {{APP_NAME}} (la “App”).

1. Información que recopilamos

Podemos recopilar y almacenar información como:

  • Datos de cuenta: nombre y correo electrónico.
  • Datos de perfil/fitness: sexo, peso, altura, medidas u otros datos que ingreses.
  • Datos de entrenamiento: ejercicios, rutinas, series, repeticiones, pesos y progreso.
  • Contenido: fotos de perfil o relacionadas con ejercicios (si decides subirlas).
  • Datos técnicos: identificadores del dispositivo, logs, fallos y eventos básicos de uso.

Nota: No vendemos tu información personal.

2. Cómo usamos la información

  • Para operar la App (crear cuenta, guardar progreso, sincronizar datos).
  • Para mejorar estabilidad y rendimiento (detección de errores y fallos).
  • Para seguridad (prevención de abuso/fraude, integridad del servicio).
  • En el futuro, para analítica y mejoras de producto (si la activamos de forma más amplia).

3. Servicios y proveedores (Firebase y otros)

Usamos servicios de terceros, principalmente Google Firebase, para:

  • Autenticación: Firebase Authentication (email/contraseña, Google, Apple cuando aplique).
  • Base de datos: Firestore/Database (almacenamiento de tu progreso).
  • Archivos: Firebase Storage (fotos u otros archivos que subas).
  • Analítica: Firebase Analytics (puede estar habilitado, y su uso puede ampliarse a futuro).
  • Errores: Firebase Crashlytics (para detectar y corregir fallos).

Estos proveedores pueden recopilar datos técnicos necesarios para prestar sus servicios (por ejemplo, eventos de fallo, identificadores de instalación).

4. Publicidad (futura)

Actualmente, la App no muestra anuncios. En el futuro podríamos incorporar publicidad (por ejemplo, mediante AdMob u otras redes). Si lo hacemos, esta Política se actualizará y puede que terceros recopilen identificadores/publicidad según su configuración y permisos.

5. Compras y suscripciones (futuras)

En el futuro podríamos ofrecer compra única para eliminar anuncios o suscripciones premium. Las compras se gestionarán normalmente a través de las plataformas (Apple App Store / Google Play). No almacenamos tu información completa de pago; la gestiona la plataforma correspondiente.

6. Retención de datos

Conservamos tus datos mientras mantengas tu cuenta activa o mientras sea necesario para operar la App. Podremos conservar cierta información limitada cuando sea requerida por seguridad o cumplimiento legal.

8. Seguridad

9. Privacidad de menores
